# Issue #191: preserve singleton generator vertices

## Scope and decisions

Ensure complete and path generators contain node IDs `0..n-1`, including the
isolated node for `n == 1`. Create the initial vertex explicitly instead of
depending solely on edge insertion. Existing edge construction is unchanged.
This is a patch-level correction of the documented vertex-count contract, not
a new API or compatibility break. No release version is changed.

- `include/nxpp/generators.hpp`: explicit vertices and singleton return documentation.
- `tests/test_edge_cases.cpp`: zero, singleton and four-node cases across eight presets.
- `CHANGELOG.md`, `SESSIONS.md` and this record: unreleased fix and task history.
