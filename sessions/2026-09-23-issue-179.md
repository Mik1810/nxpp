# Issue #179 - Verify declared Node versions for WASM

## Scope and acceptance

Align the npm engine range with a CI matrix that installs one built tarball,
checks public TypeScript declarations, and runs a graph operation on each
declared Node major. Make the release workflow wait for the same gate.

## Decisions

- Support Node 22, 24, and 26 explicitly. Node 20 is EOL; unbounded `>=20`
  also promised untested future and odd-numbered majors.
- Keep the Emscripten build in one job and upload one verified npm tarball for
  the Node-version consumer jobs. Both registries publish that same tarball
  only after the release matrix passes.
- Keep browser support and the graph API unchanged.
